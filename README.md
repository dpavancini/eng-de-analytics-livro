**Livro - Engenharia de Analytics**

Este repositório é o material de apoio para o livro "Engenharia de Analytics", escrito por Daniel Avancini. Ele contém o código, os datasets e os guias práticos para que você possa acompanhar os exemplos e exercícios apresentados na obra. O livro tem como objetivo ensinar as técnicas e os conceitos necessários para que um(a) Engenheiro(a) de Analytics domine o processo de dados de ponta a ponta, utilizando o framework Modern Data Stack (MDS).

**Conteúdo do Livro**

O livro está organizado em módulos que combinam conhecimentos de negócio com conteúdos técnicos, refletindo a natureza híbrida da profissão:

**Módulo 1: Fundamentos**

Conceitos de dados e analytics (os 5 Vs);
Técnicas de pensamento analítico;
Bancos de dados e SQL para análise.

**Módulo 2: Modelando Dados**

Data Warehouses no Modern Data Stack;
Modelagem dimensional (tabelas fato e dimensões);
Prática de modelagem e configuração com Google BigQuery;
Prática de modelagem e configuração com Databricks.

**Módulo 3: Transformando Dados**

Conceitos de ELT e ETL;
Teoria e prática de ingestão de dados;
Etapas de transformação com exemplo prático utilizando dbt.

**Tecnologias Utilizadas**

Este projeto utiliza ferramentas e tecnologias que são a base do Modern Data Stack:
**dbt (Data Build Tool)**: Ferramenta para transformação de dados;
**SQL**: Linguagem para manipulação e consulta de dados;
**Databricks**: Plataforma de data lakehouse utilizada para modelagem e análise;
**Google BigQuery**: Data Warehouse na nuvem;
**Python**: Para scripts e automação;
**Google Looker Studio (antigo Data Studio)**: Para visualização e dashboards.

**Para Quem é Este Material?**
Este repositório é ideal para:
- Analistas de Dados que desejam evoluir para a Engenharia de Analytics;
- Engenheiros de Dados que querem aprimorar suas habilidades de modelagem e transformação de dados;
- Cientistas de Dados que buscam entender melhor o fluxo de dados em produção;
- Profissionais de tecnologia em geral que querem dominar o Modern Data Stack.
