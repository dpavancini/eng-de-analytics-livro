# 1.1 Por que Engenharia de Analytics?

Nos últimos anos, o mundo dos dados passou por uma verdadeira revolução. Ferramentas de self-service analytics, machine learning, deep learning e big data se tornaram acessíveis, e a busca por profissionais de dados capazes de "revolucionar negócios" se intensificou. No entanto, a realidade muitas vezes frustra as expectativas. A geração de valor real a partir desses projetos, na prática, ainda deixa a desejar.

É nesse cenário que surge o conceito de *Modern Data Stack* (MDS), uma nova abordagem que vem se popularizando globalmente, trazendo uma filosofia de que **os dados devem ser tratados como software** e o objetivo central é a **geração de valor de negócio** de forma eficiente e escalável.

Para implementar o *Modern Data Stack (MDS)*, o desafio vai muito além de apenas contratar ferramentas (que, por sinal, já são muitas). O maior gargalo, na verdade, está em preencher a lacuna de profissionais e processos que a maioria das empresas ainda não possui. Afinal, essa expertise não costuma ser ensinada em cursos universitários tradicionais (ainda).

As equipes de analytics atuais são compostas por uma mistura de profissionais de áreas e competências distintas: TI, negócios, engenharias, ciências, entre outras. Boa parte desses profissionais nunca teve um treinamento formal na área, mas deriva seu conhecimento da prática, de blogs, competições no Kaggle ou ainda de centenas de cursos online de ciência de dados e analytics que proliferaram nos últimos anos.

Embora esse modelo de aprendizado seja crucial para suprir a demanda do mercado, a falta de uma visão holística, que geralmente vem de uma formação mais formal, somada à necessidade de combinar negócios, estatística e programação, gerou uma grande "dívida técnica" (technical debt). O resultado: muitos profissionais de dados não entendem a complexidade de rodar sistemas de analytics de ponta em produção. [^label1]. 

Na prática, a "passagem de bastão" entre o que é desenvolvido pelos analistas e cientistas de dados para se tornar um projeto com **geração de valor real** para as organizações ainda é muito complexa e ineficiente. O pior é que muitas das ferramentas e processos ensinados não se alinham com as boas práticas de engenharia de software, como versionamento, testes, CI/CD, entre outras. 

Em resumo: 

*  O **Modern Data Stack (MDS)** é uma nova metodologia de dados que está ganhando força no mercado, focada em gerar valor de negócio ao tratar dados como *software*;
* As funções de dados no MDS precisam conectar o negócio e a tecnologia, aplicando as boas práticas de desenvolvimento de *software*.


[^label1]: Em desenvolvimento de softwares, **ambiente produção (ou prod)** é o ambiente em que o sistema é utilizado pelo usuário final (por exemplo: website que está no ar) em contraponto ao **ambiente de desenvolvimento (ou dev)**.
